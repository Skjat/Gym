# Тренер — тренировки с персональным тренером на Claude

Веб-приложение (PWA) для iPhone: устанавливается из Safari на экран «Домой» и работает как обычное приложение. Аккаунт разработчика Apple не нужен.

**Что умеет**

- **Библиотека из 185 упражнений на русском:** зал, дом, улица, йога, растяжка, мобильность, бег, HIIT, пилатес, дыхание. У каждого упражнения есть описание, пошаговая техника, советы, частые ошибки, дыхание и противопоказания. Теги показывают целевые мышцы, инвентарь, место, уровень и то, что упражнение развивает (сила, гибкость, координация, баланс и т. д.).
  - **Фото и анимация:** у 111 упражнений есть фото начального и конечного положения. Они чередуются и складываются в простую анимацию движения.
  - **Видео:** кнопка «Видео техники» открывает поиск видео на YouTube. К любому упражнению можно добавить своё фото или видео.
  - **Расширенная база:** по кнопке загружаются ещё около 770 упражнений из [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain). Их описания можно перевести на русский через Claude.
- **27 готовых программ** (61 тренировка): фулбади, верх/низ, PPL, 5×5, тренировки дома и на улице, «с нуля до 5 км», подготовка к 10 км, хатха, виньяса, инь-йога, растяжка и шпагат, мобильность для офиса, табата, круговая с гирей, пилатес, дыхательные практики.
- **Тренер на Claude:**
  - Пишете запрос («40 минут в зале, ноги, колено побаливает»), и тренер собирает тренировку под вас. Он учитывает вашу историю, рабочие веса, план и восстановление по данным Garmin.
  - Ведёт и корректирует план на неделю.
  - Разбирает каждую выполненную тренировку: пульс, зоны, объём, RPE, Training Effect.
  - Запоминает важное о вас: травмы, предпочтения, рабочие веса.
  - Пополняет и правит библиотеку. Создаёт новые упражнения с описанием, техникой, ошибками, дыханием и тегами. Создаёт свои программы и меняет готовые (включая отдельные тренировки в них). Изменённые встроенные упражнения и программы помечаются «✎ изменено тренером», и их можно вернуть к оригиналу одной кнопкой. Новые — «✨ от тренера», их можно удалить.
- **Плеер тренировки:**
  - Таймеры подходов и отдыха, голосовые подсказки, учёт повторов и весов (вес подставляется из прошлой тренировки).
  - Круги и интервалы, GPS-темп для бега.
  - Живой пульс по Bluetooth с часов Garmin и предупреждение, если пульс вышел за целевую зону.
  - Подсказки тренера прямо во время тренировки. Их можно запросить кнопкой («слишком легко», «болит колено»).
- **Garmin:** каждые 3 часа сон, HRV, Body Battery, пульс покоя, готовность к тренировке, статус тренированности и активности с часов (пульс, темп, круги, подходы силовой) подтягиваются автоматически. Можно и вручную импортировать файлы .fit, .tcx или .gpx.

## 1. Установка на iPhone

1. Откройте в **Safari** адрес **https://skjat.github.io/Gym/**.
2. Нажмите «Поделиться», затем **«На экран „Домой“»**.
3. Запускайте «Тренер» с иконки. Приложение откроется на весь экран и будет работать даже без интернета: библиотека, программы и плеер доступны офлайн.

> Если адрес не открывается: в репозитории GitHub откройте **Settings → Pages**. В поле **Source** выберите «Deploy from a branch», ветку **`gh-pages`** и папку **`/ (root)`**, затем Save. Через 1–2 минуты сайт заработает. Ветку `gh-pages` собирает workflow «Deploy app» автоматически при каждом изменении кода.

## 2. Подключение Claude

1. Зайдите на **[console.anthropic.com](https://console.anthropic.com)**: Settings → Billing (пополните баланс), затем API Keys → Create Key.
2. В приложении откройте **Профиль → Claude** и вставьте ключ. Нажмите «Проверить подключение».
3. Выберите модель:
   - **Opus 5.5** — самая умная, выбрана по умолчанию;
   - **Sonnet 5.5** — быстрее и вдвое дешевле;
   - **Haiku 5.5** — копеечная.

Ключ хранится только на вашем телефоне. Приложение обращается к API Anthropic напрямую, без посредников.

Сколько это стоит: один запрос к тренеру на Opus 5.5 обходится примерно в несколько центов. Каталог упражнений в промпте кэшируется, поэтому повторные сообщения в одном диалоге дешевле. Подсказки во время тренировки выполняются в быстром режиме, по 1–2 предложения. Их частоту можно настроить или отключить в профиле.

Заполните профиль: цели, травмы, инвентарь, максимальный пульс. Тренер учитывает всё это в каждом ответе.

## 3. Подключение Garmin

Есть несколько способов, их можно совмещать. Скриншоты не требуют никакой настройки, а автоматическая синхронизация настраивается с телефона за пару минут.

### 3.0. Скриншоты из Garmin Connect — без настройки

1. После тренировки откройте её в приложении Garmin Connect и сделайте скриншоты нужных экранов: сводка, пульс и зоны, темп, отрезки или круги, Training Effect.
2. В «Тренере» есть два способа отправить их тренеру:
   - в чате нажмите 📎, выберите скриншоты и, если хотите, добавьте комментарий;
   - откройте тренировку в истории и нажмите «Приложить скриншоты из Garmin», затем «Разбор от тренера».
3. Тренер считает с картинок цифры и графики и разберёт тренировку. Так же можно прислать скриншоты сна, HRV или Body Battery.

Ссылку «Поделиться» из Garmin Connect присылать бесполезно: данные на странице Garmin Connect видны только после входа в аккаунт, поэтому ни приложение, ни Claude их не откроют. Если такая ссылка попадёт в чат, тренер попросит скриншоты. Если же настроена синхронизация (раздел 3.1), тренер найдёт эту активность в синхронизированных данных по номеру из ссылки.

### 3.1. Автоматическая синхронизация — настраивается с телефона

Garmin не даёт веб-приложениям прямой доступ к часам. Поэтому данные забирает скрипт `garmin-sync/sync.py` на бесплатных серверах GitHub Actions. Он использует библиотеку [`garminconnect`](https://github.com/cyberjunky/python-garminconnect), неофициальный API Garmin Connect. Данные **шифруются паролем синхронизации** (AES-256-GCM) и хранятся в ветке `garmin-data`. Расшифровываются они только на телефоне.

Всё настраивается в приложении: **Профиль → Garmin и пульс**. Компьютер и правка файлов не нужны.

1. **Токен GitHub.** В приложении есть ссылка на страницу создания токена. На ней:
   - войдите в GitHub;
   - Repository access → *Only select repositories* → `Skjat/Gym`;
   - Permissions: *Actions* — Read and write, *Secrets* — Read and write, *Contents* — Read-only;
   - Generate token, скопируйте токен и вставьте его в приложение. Нажмите «Проверить доступ».
2. **Пароль синхронизации.** Нажмите «Создать и сохранить в GitHub». Приложение придумает надёжный пароль и сохранит его на телефоне и в секрете `GARMIN_SYNC_PASSPHRASE` репозитория. Запишите пароль: он понадобится, если ставить приложение на другое устройство. Для этого есть пункт «Уже настроено на другом устройстве?».
3. **Вход в Garmin.**
   - Введите почту и пароль Garmin Connect и нажмите «Войти в Garmin». Через минуту вход завершится.
   - Если включена двухфакторная защита, Garmin пришлёт код в письме или приложении. Введите его в появившееся поле, через минуту данные загрузятся.
   - Если закрыть приложение, пока ждёте код, при следующем открытии экран Garmin снова покажет поле для кода. Код действует около 30 минут.

Как это устроено:
- Пароль Garmin не сохраняется ни в приложении, ни в репозитории. Он зашифрованным уходит в синхронизацию один раз. Дальше синхронизация работает по токенам Garmin, которые обновляются сами и хранятся в зашифрованном виде.
- Синхронизация идёт каждые 3 часа. Кнопка «Синхронизировать сейчас» запускает её сразу, например после тренировки.
- Если когда-нибудь Garmin попросит войти заново, на экране Garmin будет сообщение, тогда повторите шаг 3.

После синхронизации тренировки в приложении сами связываются с активностями на часах по времени. Если во время тренировки пульс не транслировался, он подтянется из Garmin. Тренер видит всё это при разборе и при составлении следующих тренировок.

Токен GitHub хранится только на телефоне и даёт доступ только к этому репозиторию. Если телефон потерян, удалите токен на github.com: Settings → Developer settings → Fine-grained tokens.

> Workflows по расписанию работают только из основной (default) ветки репозитория. GitHub отключает их, если в репозитории 60 дней не было активности. Если синхронизация остановилась, включите её снова на вкладке Actions.

<details>
<summary>Другие способы входа (через секреты репозитория)</summary>

Вместо входа из приложения можно задать секреты вручную на github.com: Settings → Secrets and variables → Actions.
- `GARMIN_SYNC_PASSPHRASE` — обязательно, тот же пароль, что и в приложении.
- Вход, один из вариантов:
  - `GARMIN_EMAIL` и `GARMIN_PASSWORD` — для аккаунта без двухфакторной защиты;
  - `GARMIN_TOKENS` — строка токенов, которую выводит `python garmin-sync/login.py` на компьютере.

### 3.2. Живой пульс во время тренировки

1. На часах включите **трансляцию пульса**: Настройки → Датчики и аксессуары → Пульс на запястье → «Трансляция пульса». На многих моделях также можно включить «Трансляцию во время активности».
2. Safari на iPhone не поддерживает Bluetooth для сайтов. Для живого пульса откройте приложение в бесплатном браузере **Bluefy** (App Store). В плеере нажмите «Пульс с часов».
3. В плеере будут видны пульс и зона. Если пульс выйдет выше целевой зоны, приложение предупредит голосом, а тренер получит пульс в своих подсказках.

Без Bluetooth всё остальное работает, а пульс подтянется из Garmin после синхронизации.

### 3.3. Импорт файла

Откройте Garmin Connect (сайт), затем активность → ⚙ → «Экспорт оригинала» (.zip/.fit) или «Экспорт в TCX/GPX». В приложении выберите файл в разделе **Профиль → Garmin и пульс** или в **Истории** на вкладке Garmin.

## 4. Как пользоваться

- **Сегодня:** напишите тренеру, какую тренировку хотите. Здесь же видны восстановление, план на неделю и последние тренировки.
- **Тренер:** чат. Тренировку, которую он соберёт, можно сразу начать, открыть или поставить в план.
- **🎤 Диктовка:** запрос тренеру можно надиктовать. Кнопка микрофона есть в чате, на главной и в «Спросить тренера» во время тренировки. При первом нажатии Safari попросит доступ к микрофону и распознаванию речи. Если встроенное распознавание недоступно, нажмите микрофон на клавиатуре iPhone.
- Недописанное сообщение сохраняется при переключении вкладок и даже после закрытия приложения. Если тренер ещё отвечает, ответ допишется, пока вы на другой вкладке.
- **Программы и Упражнения:** библиотека с фильтрами по направлению, месту, мышцам, инвентарю, развиваемым качествам и уровню. Фильтр «✨ От тренера» показывает всё, что тренер создал или изменил.
- **Изменить с тренером:** кнопка есть на странице упражнения, программы и тренировки. Она открывает чат с заготовкой вроде «Измени программу „…“:», вам остаётся дописать, что поменять. Новые упражнения и программы можно просить прямо в чате или кнопками «Добавить упражнение с тренером» и «Новая программа с тренером».
- **Плеер:** держите экран включённым (приложение само не даёт ему гаснуть). Таймеры не сбиваются, даже если свернуть приложение.
  - Отжимания и другие упражнения на повторы: «Подход выполнен».
  - Упражнения на время: таймер сам переключит на отдых.
  - Тренировку можно поставить на паузу, а упражнение пропустить.
- После тренировки отметьте RPE и самочувствие, затем нажмите **«Разбор от тренера»**.
- **Профиль → Данные:** резервная копия. Все данные хранятся на телефоне, поэтому время от времени скачивайте копию.

## 5. Разработка

```bash
npm install
npm run dev            # http://localhost:5173
npm run validate-data  # проверка библиотеки упражнений и программ
npm run build          # сборка в dist/
```

Структура:

- `src/data/exercises/*.json`, `src/data/programs/programs.json` — контент. Схема описана в `docs/CONTENT_SPEC.md`.
- `src/coach/` — тренер: системный промпт, инструменты (`create_workout`, `update_training_plan`, `get_garmin_data` и др.) и цикл диалога с Claude (`@anthropic-ai/sdk`, стриминг, история только дописывается).
- `src/pages/` — экраны. `src/lib/` — таймеры, пульсовые зоны, Bluetooth, GPS, импорт FIT/TCX/GPX, расшифровка данных Garmin.
- `garmin-sync/` — скрипт синхронизации Garmin Connect. `.github/workflows/` — синхронизация и публикация на GitHub Pages.

Фото упражнений взяты из [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain). FIT-файлы читаются через Garmin FIT SDK.
